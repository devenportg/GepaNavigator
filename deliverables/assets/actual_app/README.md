# Снимки приложения для релизной презентации

PNG-файлы 01–05 сняты непосредственно из запущенного GepaNavigator (Chromium, viewport 1600×900) после входа в локальную демонстрацию. Они не перерисованы и не собраны из отдельных компонентов. Демо-база синтетическая; имена заменены на `Демо-пациент NN`, контакты удалены, пользователь обозначен как `Демо-врач`.

- `01_worklist.png` — список наблюдения;
- `02_patient_card.png` — открытая карточка и план;
- `03_visit_editor.png` — редактор приёма с черновиком локального шаблона;
- `04_care_tasks.png` — очередь обзвона;
- `05_analytics.png` — аналитика демо-базы (не результаты пилота).

Снимки 01–05 встроены в текущую презентацию. Отдельные старые изображения в других папках `assets/` в ней не используются.
