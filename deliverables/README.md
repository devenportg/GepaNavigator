# GepaNavigator — комплект релиза

## Для выступления используйте только эти два файла

1. **`GepaNavigator_release.pptx`** — актуальная презентация, 18 слайдов.
2. **`GepaNavigator_speech.docx`** — сценарий к той же версии.

Презентация пересобрана на единой типографической основе (Arial для текста слайдов). Экраны приложения на слайдах 4–8 — **снимки из запущенного приложения**, а не нарисованные интерфейсы. Исходные снимки находятся в `assets/actual_app/`; они сделаны в Chromium на локальном демо-контуре.

## Проверено

- PPTX открывается как файл презентации и содержит 18 слайдов.
- Сервер: 48 тестов; интерфейс: 16; сквозные сценарии: 4 (всего 68).
- Production-сборка интерфейса проходит.
- Снимки сделаны на обезличенной синтетической базе. Показатели на экране аналитики — демонстрационные, не результаты пилота.

## Ограничения прототипа

Это локальный программный прототип, а не внедрённая система. Боевые подключения к ГИС ЭЗ РТ, МИС и лабораториям не выполнены; тестовые события интеграции имитируются. Клинические правила требуют проверки медицинскими специалистами, а промышленное применение — правовой и ИБ-экспертизы. YandexGPT выключен по умолчанию; в скриншоте черновик создан локальным шаблоном. Реальные данные пациентов не используются.

## Архив

`archive/` хранит прошлые варианты только для истории. В том числе предыдущая редакция с нарисованными векторными экранами помещена туда после обратной связи и **не является актуальной**. Не используйте архивные файлы для выступления.
