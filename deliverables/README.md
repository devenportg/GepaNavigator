# GepaNavigator — комплект релиза

## Использовать для выступления

1. **`GepaNavigator_release.pptx`** — единственная актуальная презентация (18 слайдов).
2. **`GepaNavigator_speech.docx`** — сценарий именно к этой 18-слайдовой презентации.

Начинайте с этих двух файлов. Сценарий поясняет границы прототипа и отмечает, какие шаги относятся к плану.

## Что уже проверено

- Презентация открывается как PPTX и содержит 18 слайдов.
- Сервер: 48 тестов пройдены; интерфейс: 16; сквозные сценарии: 4 (всего 68).
- Production-сборка интерфейса проходит.
- Проверки сделаны на синтетических данных. Они не заменяют клиническую экспертизу и проверку информационной безопасности.

## Важные ограничения

Это рабочий программный прототип, а не внедрённая система: подключение к боевым ГИС ЭЗ РТ/МИС не выполнено, реальные интеграции имитируются. Клинические правила требуется сверить с медицинскими специалистами до применения. YandexGPT выключен по умолчанию; реальных медицинских данных в демонстрации нет. Слайды о расширении продукта, пилоте и поставке описывают планы, а не завершённые работы.

## Архив

`archive/` содержит только исторические материалы, не предназначенные для показа вместо основного релиза:

- `GepaNavigator_release_13slides_prev.pptx` — прежняя 13-слайдовая редакция;
- `GepaNavigator_release_19slides_dark_prev.pptx` — прежняя тёмная 19-слайдовая редакция;
- `GepaNavigator_speech_13slides_prev.docx` — прежний сценарий к 13 слайдам;
- `GepaNavigator_audit.docx` — прежний аудит/заметки к ранней редакции, не источник актуальной версии.

Их оставили для истории и сравнения; **не используйте их для выступления**. Канонический комплект — два файла из списка в начале.
