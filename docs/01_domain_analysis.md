# 1.1 Анализ предметной области

## Название проекта
**ГепаНавигатор (GepaNavigator)** — цифровой модуль диспансерного наблюдения пациентов с хроническими гепатитами, встраиваемый в Единую государственную информационную систему здравоохранения Республики Татарстан (ГИС ЭЗ РТ).

---

## 1. Контекст и масштаб проблемы

Хронические вирусные гепатиты (ВГВ, ВГС, ВГД) являются одной из ведущих причин цирроза печени и гепатоцеллюлярной карциномы в мире и в России. В РФ, по данным презентации, насчитывается **688 307** пациентов с гепатитом C (2023 г.), отмечается **+9,1 %** прирост впервые выявленных случаев (2024 г.), а за 2025 г. выявлено **58 200** новых случаев по скринингу.

В Республике Татарстан развёрнута региональная ГИС ЭЗ РТ, аккумулирующая порядка **50 млн** медицинских документов (2024 г.). Несмотря на наличие данных, эффективность диспансерного наблюдения остаётся низкой, поскольку данные не превращаются в конкретные действия на стороне врача.

## 2. Нормативно-клиническая база

Работа модуля опирается на следующие документы:

| Документ | Роль в системе |
|---|---|
| Клинические рекомендации Минздрава РФ по хроническим гепатитам B, C, D | Определяют схему наблюдения, периодичность визитов и перечень обследований |
| Приказ Минздрава РФ № 168н «О порядке проведения диспансерного наблюдения...» | Регулирует порядок постановки и снятия с диспансерного учёта |
| Приказы об организации оказания помощи инфекционным больным | Определяют структуру оказания помощи |
| Федеральный регистр больных вирусными гепатитами (ФРВГ) | Источник данных о пациентах и федеральной отчётности |
| 152-ФЗ «О персональных данных», приказ ФСТЭК №21, Постановление Правительства №1119 | Требования к защите медицинских данных |
| 44-ФЗ, 223-ФЗ | Порядок госзакупок (использование ПО из реестра росПО) |

## 4. Участники процесса (стейкхолдеры)

| Роль | Кто это | Потребность / «боль» |
|---|---|---|
| **Врач-инфекционист** | Ведёт пациента в поликлинике/стационаре | Ведёт списки в 4 системах + Excel, вручную собирает список на приём, узнаёт о выпавшем пациенте постфактум (с осложнением) |
| **Врач-гастроэнтеролог** | Соответствующий профиль | Аналогичная проблема ведения хронических пациентов |
| **Пациент с гепатитом** | Житель РТ с диагнозом B18.* | Не всегда знает, когда и что нужно сдать; забывает о визитах; теряется в маршруте |
| **Заведующий отделением / главврач МО** | Руководитель медицинской организации | Видит нагрузку на врачей и охват наблюдением по своей МО |
| **Минздрав РТ** | Региональный орган управления здравоохранением | Нуждается в реальной картине охвата, приверженности, доли УВО в регионе в реальном времени |
| **Оператор ГИС ЭЗ РТ** | Технический оператор региональной МИС | Нуждается в нативно встроенном модуле, а не в отдельном приложении |
| **НМИЦ ФПИ** | Федеральный проект по гепатиту C | Получает агрегированные отчётные данные |
| **Лаборатории и центры эластометрии** | Поставщики диагностических услуг | Отправляют результаты анализов и инструментальных исследований |

## 5. Существующие решения и их недостатки

На основе кабинетного исследования и интервью (по данным презентации):

| Решение | Наблюдение по КР | Напоминания пациенту | Нативная интеграция в ГИС ЭЗ РТ |
|---|---|---|---|
| МИС qMS (СП.АРМ) | частично | нет | нет |
| БАРС.Здравоохранение | частично | нет | через интеграцию |
| ЕМИАС (Москва) | да | да | нет — другой регион |
| МИС «Инфоклиника» | частично | нет | нет |
| ФРВГ + Excel | только учёт | нет | частично |
| **ГепаНавигатор** | **да** | **да** | **да, нативно** |

**Ключевой инсайт исследования:** проблема не в данных (они уже есть в ГИС ЭЗ РТ и ФРВГ), а в отсутствии **клинического слоя**, который превращает массив данных в конкретные действия: кто должен прийти, когда и кто уже выпал.

## 7. Технологический контур

Вся инфраструктура размещается в российском контуре (Yandex Cloud / on-premise), с соблюдением 152-ФЗ, ФСТЭК, требованиями аттестации. Используются сервисы Яндекса (в реестре росПО):
- **Yandex Cloud** — вычисления, управляемые БД, объектное хранилище
- **YandexGPT** — ассистент врача: выжимка истории, черновик заключения
- **Yandex SpeechKit** — голосовой ввод заключений с адаптацией к медлексике
- **Yandex Vision / OCR** — распознавание бумажных анализов и выписок
- **Yandex DataLens** — BI-дашборды для Минздрава и главврачей
- **Yandex Tracker + Wiki** — разработка и база знаний
