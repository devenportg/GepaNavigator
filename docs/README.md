## 🎯 Ключевой тезис системы

> Гепатит C излечим — но пациент выпадает из наблюдения: **данные в системе есть, а действий по ним нет.** ГепаНавигатор добавляет **клинический слой** поверх ГИС ЭЗ РТ, который превращает накопленные данные в конкретные действия врача и напоминания пациенту.

## 🗺️ Краткая сводка модулей

1. **Автоматический регистр** — постановка/снятие по триггерам (B18.*, ПЦР+, ФРВГ).
2. **Клинический слой (мотор правил КР)** — индивидуальный план наблюдения, расчёт просрочек, контроль УВО-12.
3. **Рабочее место врача (одно окно)** — список пациентов на приём, карточка, чек-лист, черновик заключения (GPT), голосовой ввод (SpeechKit), OCR (Vision).
4. **Care Management** — эскалация просрочек, задачи медперсоналу, журнал обзвона.
5. **Коммуникации с пациентом** — СМС/push/Госуслуги/голосовой робот.
6. **Интеграции** — ГИС ЭЗ РТ, ЕГИСЗ, ФРВГ, ЛИС, СМЭВ, НСИ.
7. **Аналитика** — дашборды для врача, МО, Минздрава (DataLens).
8. **Администрирование и ИБ** — роли, аудит, ФСТЭК/152-ФЗ.
